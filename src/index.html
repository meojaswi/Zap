Search hotkey

Opens the Zap search box from any app. Click the box and press the new combination.

Good choices: Ctrl+Shift+Space, Alt+;, Pause, ScrollLock, F13–F24.

Expand triggers as I type

Type `pemail in any app and it becomes your email, without opening the search box. This needs a keyboard hook that sees your keystrokes. Zap only keeps the last few characters in memory and never saves or logs them.

Excluded apps

Triggers typed in these apps are ignored (inline mode only). One program name per line, e.g. valorant.exe.

Start with Windows

Launch Zap quietly in the system tray when you sign in.

Updates

You're on Zap . Zap checks GitHub about once an hour and notifies you when a new version is ready. No snippets or usage data are sent.

Backup

Export saves your snippets as a plain, unencrypted JSON file, so keep it somewhere safe. Importing updates snippets with the same trigger.

How Zap protects your data

  • Snippets are encrypted on disk with Windows DPAPI, so only your Windows account can read them.
  • Pasted text is kept out of Win+V clipboard history and cloud clipboard sync, and your previous clipboard text is put back.
  • Sensitive snippets are typed key by key and never go through the clipboard.
  • Keystrokes are never written to disk or logged.
  • The only thing Zap connects to is GitHub, to check for updates. You can turn that off above.
  • Updates are signed, and Zap refuses any download that isn't.
  • Don't store passwords here. A password manager is the right place for those.
