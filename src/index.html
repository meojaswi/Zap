Search hotkey

Opens the Zap search box from any app. Click the box and press the new combination.

Good choices: Ctrl+Shift+Space, Alt+;, Pause, ScrollLock, F13–F24.

Expand triggers as I type

Type `email in any app and it becomes your email, without opening the search box. This needs a keyboard hook that sees your keystrokes. Zap only keeps the last few characters in memory and never saves or logs them.

Secondary trigger prefix

Some websites block characters like ` in their fields. Set a prefix of letters, like zz, and every trigger that starts with a symbol also works with it. Leave it empty to turn this off.

Excluded apps

Triggers typed in these apps are ignored (inline mode only). One program name per line, e.g. valorant.exe.

Start with Windows

Launch Zap quietly in the system tray when you sign in.

Updates

You're on Zap . Zap checks GitHub about once an hour and notifies you when a new version is ready. Nothing about you or your snippets is sent.

Stats

Counts how often each snippet is used and the last date, to estimate the typing time Zap saves you. Nothing you type is recorded, and stats stay on this PC, encrypted. Turn this off to stop counting.

    Anonymous user count

    Once a day, Zap sends a random ID and its version number so we can count how many people use it. The ID is made on this PC and isn't linked to you, your PC or your snippets, and the server keeps only a count, not the ID. Turning this off deletes the ID.

    Backup

    Export saves your snippets as a plain, unencrypted JSON file, so keep it somewhere safe. Importing updates snippets with the same trigger.

    How Zap protects your data

    • Snippets are encrypted on disk with Windows DPAPI, so only your Windows account can read them.
    • Pasted text is kept out of Win+V clipboard history and cloud clipboard sync, and your previous clipboard text is put back.
    • Sensitive snippets are typed key by key and never go through the clipboard.
    • Keystrokes are never written to disk or logged.
    • Usage stats (how often each snippet is used, and the last date) stay on this PC, encrypted. You can turn them off or reset them above.
    • Zap connects to GitHub to check for updates, and once a day to our server for the anonymous user count: a random ID and the version, nothing else. You can turn both off above.
    • Updates are signed, and Zap refuses any download that isn't.
    • Don't store passwords here. A password manager is the right place for those.
